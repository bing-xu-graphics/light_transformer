## Infinigen

The procedural indoor scene workflow is based on [Infinigen](https://github.com/princeton-vl/infinigen) from the Princeton Vision & Learning Lab. The project used version `v1.12.1` through a [project fork](https://github.com/Galaxeaaa/infinigen).

No Infinigen source code or modified upstream files are distributed in this repository. The downloadable teaser scene contains generated meshes and textures and includes the Infinigen BSD 3-Clause license notice.
